# 機能設計書（外部設計）

版: v0.1 / ステータス: Draft

目的: 機能一覧（functional-list.md）に基づき、ユーザー視点の動作仕様・画面・入力項目・権限・エラー・境界条件を定義する。

共通方針
- 対応ロール: ADMIN/COACH/STUDENT（RBACで制御）
- デバイス: PC/スマートフォン（375/768/1024/1440）に対応
- バリデーション: クライアント（zod）/サーバ（zod + Prisma 制約）の二段構え
- 画面: MUI コンポーネント、アクセシビリティ基本対応

---

## 1. 認証/アカウント
- 対象機能: F-AUT-001/002/003
- 画面
  - サインイン: メール入力 → ワンタイムリンク送付（Passwordless）
  - プロフィール: 氏名/アイコン編集、保存
- フロー
  - サインイン: メール入力 → 送信 → メールリンク → 認証完了 → ダッシュボードへ遷移
  - サインアウト: メニュー → サインアウト → 認証解除
- 入力項目
  - Email（必須/メール形式）
  - 氏名（任意、1〜64文字）
- 権限
  - 認証不要: サインイン画面
  - 認証必要: プロフィール編集（自身のレコードのみ）
- エラー/境界
  - 不正メール形式/リンク期限切れ/既存セッション
- 受入
  - 成功/失敗トースト表示、セッションが tRPC/UI で一貫

## 2. ユーザープロファイル/台帳
- 対象機能: F-USR-001/002/003
- 画面
  - 生徒台帳/コーチ台帳（一覧/検索/詳細）
- フロー
  - ADMIN が台帳から検索 → 詳細閲覧/編集 → 保存
- 入力項目（例）
  - 生徒: レベル（enum）、生年月日（YYYY-MM-DD）、保護者名/連絡先
  - コーチ: 資格（文字列）、自己紹介（最大1024文字）
- 権限
  - ADMIN のみ編集可、COACH/本人は自分のプロフィール閲覧可
- エラー/境界
  - 重複メール、レベル未定義、長文オーバー
- 受入
  - 検索/ページング応答 < 500ms、必須項目バリデーション

## 3. スケジュール/枠（LessonSlot）
- 対象機能: F-SCH-001/002/003
- 画面
  - カレンダー（月/週/日）、枠作成ダイアログ、枠詳細
- フロー
  - ADMIN/COACH: 枠作成 → 日時/コート/レーン/定員/レベル/コーチ → 保存
  - ALL: フィルタ（コーチ/レーン/レベル）で表示を絞込
- 入力項目
  - 開始/終了日時、レーン、定員（1〜50）、レベル（enum）、担当コーチ、種別（group/private）
- 権限
  - 枠 CRUD: ADMIN/COACH（COACHは自担当領域に限定）
- エラー/境界
  - レーン二重割当、終了<開始、定員超え
- 受入
  - カレンダー表示が 375/768/1024/1440 で崩れない、作成編集が成功

## 4. 予約
- 対象機能: F-RES-001/002/003/004
- 画面
  - 予約作成ダイアログ、予約一覧、自分の予約詳細
- フロー（予約作成）
  1) 学生が枠を選択 → 予約
  2) サーバで定員/重複/制約を検証 → OK なら作成、超過ならウェイトリスト
  3) UI に反映、通知（将来）
- フロー（キャンセル/振替）
  - キャンセル: 自分の予約 → キャンセル理由任意 → 取消
  - 振替: 同レベル枠へ移動（制約: 期限/残数（M4 以降））
- 入力項目
  - 予約対象枠、メモ（任意）、キャンセル理由（任意）
- 権限
  - STUDENT: 自分の予約 CRUD
  - COACH: 枠の参加者管理（出席と併せて）
- エラー/境界
  - 定員超過/重複予約/期限超過/権限なし
- 受入
  - 正常/異常パスのトースト・UI更新、一覧反映 < 1s

## 5. 出欠/コーチ業務
- 対象機能: F-ATT-001/002, F-COA-001
- 画面
  - 出欠入力（枠別一覧/チェックボックス/一括）、シフト入力/担当割当
- フロー
  - 出欠: コーチが枠参加者に present/absent/late を記録
  - シフト: 希望入力 → 管理側で担当割当 → 反映
- 入力項目
  - 出欠ステータス、備考（任意）
- 権限
  - COACH のみ編集、ADMIN は上書き可
- エラー/境界
  - 既記録の上書き/巻き戻し、当日締切
- 受入
  - モバイルで 44px タップ幅、一覧スクロール最適化

## 6. 試合/成績
- 対象機能: F-MAT-001/002/003
- 画面
  - 試合イベント詳細、エントリー、結果入力、ランキング
- フロー
  - イベント作成 → エントリー登録 → 対戦表生成 → 試合結果入力 → 集計/ランキング
- 入力項目
  - 形式（シングル/ダブル）、スコアテキスト（6-4 等）、勝者指定
- 権限
  - 作成/編集: ADMIN/COACH、閲覧: ALL、結果参照: ALL
- エラー/境界
  - 不正スコア、同一選手重複、チーム不整合
- 受入
  - 集計が期待値と一致、期間/レベルで絞込可

## 7. ダッシュボード/KPI
- 対象機能: F-KPI-001/002/003
- 画面
  - KPI カード（予約率/出席率/稼働率/売上/成績）と時系列チャート
- フロー
  - 期間/レベル/コーチ/レーンを指定 → 集計 API 呼び出し → 可視化
- 指標定義（抜粋）
  - 予約率 = 予約数 / 枠総数、出席率 = 出席 / 予約、稼働率 = 実施時間/稼働可能時間
- 権限
  - ADMIN/COACH: 閲覧、学生は自身の一部統計のみ（将来）
- 受入
  - p95 < 500ms、代表データで数値一致

## 8. 設定/マスタ
- 対象機能: F-SCH-003（コート/レーン）、料金/ポリシー（将来）
- 画面
  - コート/レーン一覧、追加/編集/削除
- 入力項目
  - コート名、屋内外、レーン数/名称
- 権限
  - ADMIN 限定

## 9. 請求/プラン（軽量）
- 対象機能: F-BIL-001/002
- 画面
  - プラン作成、残数/有効期限表示
- ルール
  - 予約時に残数を検証、キャンセル/振替時に戻し
- 権限
  - 管理: ADMIN、閲覧: STUDENT（自身）

## 10. 通知
- 対象機能: F-NTF-001
- 対象イベント
  - 予約/変更/キャンセル、出欠前リマインド
- 内容
  - 件名/本文テンプレート（多言語は将来）
- 配信制御
  - オン/オフ、レート制御、再送戦略（失敗時リトライ）

## 共通仕様（UI/UX/レスポンシブ）
- レイアウト
  - デスクトップ: AppBar + Permanent/Temporary Drawer
  - モバイル: 簡素ヘッダ + ボトムナビ/スワイプドロワー
- フォーム
  - `react-hook-form` + zod、エラーメッセージとフォーカス誘導
- 状態表示
  - ローディング（Skeleton/Spinner）、空状態、成功/失敗トースト
- レスポンシブ
  - 主要ページが 375/768/1024/1440 で視認性・操作性合格、タップ領域 >= 44px

## 非機能（該当機能で要求されるもの）
- 性能: API p95 < 500ms（集計を除く）
- セキュリティ: RBAC 漏れなし、CSRF/XSS 基本対策
- アクセシビリティ: フォーカス可視、ラベル/コントラスト、キーボード操作
