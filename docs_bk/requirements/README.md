## システム要件（デバイス/ブラウザ）
- デバイス: PC とスマートフォンからのアクセスを正式サポート（タブレットは将来検討）
- ビューポート目標: 375px（モバイル）/ 768px / 1024px / 1440px（デスクトップ）
- ブラウザ: 最新の Chrome / Safari / Edge（各自動更新2世代）
- アクセシビリティ: 重要導線はキーボード操作可能、コントラスト比準拠
